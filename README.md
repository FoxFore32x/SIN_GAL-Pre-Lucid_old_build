# SIN_GAL: Pre-Lucid

This is a ficticious Arcade style Platformer/Beat em Up videogame made by an also ficticious company called "SIN_GAL". The objective is to uncover the story of company while you play the incomplete version of the Arcade game.

It's being made for the PC and Dreamcast platforms by the use of different engines.

### Engines/Libraries Used

[Game Maker Studio 2]([https://gamemaker.io/en]) - A Famous game engine focused on 2D game development
